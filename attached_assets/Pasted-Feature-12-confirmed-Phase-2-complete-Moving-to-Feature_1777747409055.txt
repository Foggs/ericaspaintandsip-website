## Feature: Design Polish and Animations

### Description
Full visual implementation pass across all pages. Apply the final color system,
typography, spacing, and Framer Motion animations. The site should feel modern,
dynamic, and energetic — reflecting the paint-and-sip brand.

### Files Involved
- artifacts/cms/tailwind.config.ts (define color tokens and typography scale)
- artifacts/cms/src/app/(frontend)/layout.tsx (global font imports, base styles)
- All page files under src/app/(frontend)/
- All component files under components/

### Design Tokens to Define in tailwind.config.ts
- Primary: deep purple (e.g. #6B21A8 or brand-matched equivalent)
- Accent: warm coral or gold for CTAs
- Background: off-white / soft cream
- Font families: display font (Playfair Display or Fraunces via Google Fonts) for headings,
  clean sans-serif (Inter or DM Sans) for body

### Animation Constraints
- Use Framer Motion for: page transitions, card hover states, hero entrance animations
- Do NOT add animation to form elements — keep forms fast and functional
- Animations must respect prefers-reduced-motion
- Keep animation durations under 400ms for interactive elements

### General Constraints
- Mobile-first — verify every page at 375px, 768px, and 1280px widths
- Use cn() from lib/utils.ts for conditional class merging
- No inline style props except for truly dynamic computed values
- Do NOT change any data-fetching logic, API routes, or collection definitions
